## 摘要
从粗到精的自回归建模最近在视觉运动策略学习中展现出强大的潜力，它结合了自回归方法的推理效率与基于扩散策略的全局轨迹连贯性。然而，现有方法依赖于离散动作分词器，将连续动作序列映射到码本索引，这种设计继承自图像生成领域，在图像生成中，学习压缩对于高维像素数据是必要的。我们观察到机器人动作本质上是低维连续向量，对此类数据进行分词会引入不必要的量化误差和多阶段训练流程。在这项工作中，我们提出了分层流策略（HiFlow），这是一种无需分词的从粗到精的自回归策略，直接作用于原始连续动作。HiFlow 通过简单的时序池化，从每个动作块中构建多尺度连续动作目标。具体而言，它对连续的动作窗口取平均值以生成粗略摘要，并在更精细的时序分辨率下进行细化。整个模型在单一阶段内进行端到端训练，消除了对独立分词器的需求。在 MimicGen、RoboTwin 2.0 和真实环境中的实验表明，HiFlow 一贯优于现有方法，包括基于扩散和基于分词的自回归策略。

## Abstract
Coarse-to-fine autoregressive modeling has recently shown strong promise for visuomotor policy learning, combining the inference efficiency of autoregressive methods with the global trajectory coherence of diffusion-based policies. However, existing approaches rely on discrete action tokenizers that map continuous action sequences to codebook indices, a design inherited from image generation where learned compression is necessary for high-dimensional pixel data. We observe that robot actions are inherently low-dimensional continuous vectors, for which such tokenization introduces unnecessary quantization error and a multi-stage training pipeline. In this work, we propose Hierarchical Flow Policy (HiFlow), a tokenization-free coarse-to-fine autoregressive policy that operates directly on raw continuous actions. HiFlow constructs multi-scale continuous action targets from each action chunk via simple temporal pooling. Specifically, it averages contiguous action windows to produce coarse summaries that are refined at finer temporal resolutions. The entire model is trained end-to-end in a single stage, eliminating the need for a separate tokenizer. Experiments on MimicGen, RoboTwin 2.0, and real-world environments demonstrate that HiFlow consistently outperforms existing methods including diffusion-based and tokenization-based autoregressive policies.

#### 1. 核心问题与研究动机
*   **研究背景**：在机器人视觉运动策略学习中，扩散模型（DM）虽能生成全局连贯的轨迹但推理延迟高；自回归模型（AM）推理效率高但难以捕捉长程全局结构。近期出现的“从粗到细”逐尺度自回归模型（如 CARP）试图结合两者优点。
*   **核心问题**：现有的逐尺度方法（借鉴自图像生成）依赖**离散动作分词器（VQ-VAE）**。作者指出，机器人动作是低维连续向量，使用分词器会带来：
    1.  **量化误差**：离散化导致精度损失。
    2.  **复杂流程**：需要多阶段训练（先训练分词器，再训练策略）。
    3.  **设计开销**：不同机器人平台需要专门设计分词器。
*   **研究目的**：提出一种无需分词、直接在连续空间进行从粗到细建模的单阶段训练策略。

#### 2. 方法论：HiFlow 框架
HiFlow 由两个核心组件构成：**ScaleAR Transformer**（负责生成条件特征）和 **ActionFlowNet**（负责生成连续动作）。

*   **核心思想**：放弃离散码本，利用简单的**时序池化（Temporal Pooling）**构建多尺度目标，并结合**流匹配（Flow Matching）**技术在每个尺度上生成连续动作。
*   **关键技术细节**：
    *   **多尺度表示构建**：通过确定性的时序平均将 $T$ 步动作块下采样为不同分辨率（如 1, 2, 4, ..., $T$）。公式表示为：$a^{(i)} = \text{Down}(a, i)$，其中 $i$ 为尺度大小。
    *   **ScaleAR Transformer**：采用尺度间因果掩码（Scale-wise Causal Mask），确保细尺度预测仅依赖于粗尺度特征。输入是前一尺度的线性上采样结果。
    *   **尺度相关流匹配（ActionFlowNet）**：在每个尺度 $i$ 上，学习一个速度场 $v^{(i)}$，将高斯噪声 $\epsilon$ 转化为目标动作 $a^{(i)}$。
        *   插值公式：$x_\tau^{(i)} = (1-\tau)a^{(i)} + \tau\epsilon$。
        *   目标速度：$v^{(i)} = \epsilon - a^{(i)}$。
    *   **单阶段训练**：通过加权损失函数 $L = \frac{1}{|S|} \sum_{i \in S} \frac{i}{T} \|\hat{v}^{(i)} - v^{(i)}\|^2$ 进行端到端训练，无需预训练分词器。

#### 6. 主要结论与发现

*   **尺度效应**：实验发现 {1, 2, 4, 8} 的四尺度配置最为平衡；尺度过少会导致跨度太大，尺度过多则可能引入累积误差。

#### 7. 优点与亮点
*   **架构简化**：彻底去除了 VQ-VAE，简化了机器人策略的训练管线，使其更易于部署到新硬件。
*   **精度提升**：通过流匹配在连续空间直接回归，保留了动作的欧几里得几何特性，生成的轨迹更平滑。
*   **推理效率**：保留了逐尺度自回归的并行性，每个尺度内的动作可以并行生成，且流匹配通常比标准扩散模型需要更少的采样步数。

#### 8. 不足与局限
*   **推理开销**：虽然比扩散模型快，但由于每个尺度都需要进行流匹配迭代（如 25 步），总的神经网络前向传播次数仍高于纯粹的单步自回归模型。

*   **超参数敏感性**：虽然对尺度配置有鲁棒性，但流匹配的采样步数和尺度权重分配仍需针对不同任务进行微调。
