## 摘要
视觉-语言-动作 (VLA) 模型旨在根据视觉观测和自然语言指令控制机器人进行操作。然而，现有的分层和自回归范式通常会引入架构开销，面临时间不一致和长时程误差累积的问题，并且缺乏在不添加额外模块的情况下捕获环境动力学的机制。为此，我们提出了 MMaDA-VLA，这是一个完全原生的预训练扩散 VLA 大模型，它在单一框架中统一了多模态理解与生成。我们的核心思想是一种原生的离散扩散公式，它将语言、图像和连续机器人控制嵌入到一个离散的 token 空间中，并使用掩码 token 去噪训练单个骨干网络，以并行地联合生成未来的目标观测和动作块 (action chunk)。迭代去噪实现了全局、无序的细化，在提高长时程一致性的同时，将动作锚定在预测的未来视觉结果中，而无需辅助世界模型。在模拟基准测试和现实世界任务中的实验表明，该模型达到了最先进的性能，在 LIBERO 上实现了 98.0% 的平均成功率，在 CALVIN 上实现了 4.78 的平均长度。

## Abstract
Vision-Language-Action (VLA) models aim to control robots for manipulation from visual observations and natural-language instructions. However, existing hierarchical and autoregressive paradigms often introduce architectural overhead, suffer from temporal inconsistency and long-horizon error accumulation, and lack a mechanism to capture environment dynamics without extra modules. To this end, we present MMaDA-VLA, a fully native pre-trained large diffusion VLA model that unifies multi-modal understanding and generation in a single framework. Our key idea is a native discrete diffusion formulation that embeds language, images, and continuous robot controls into one discrete token space and trains a single backbone with masked token denoising to jointly generate a future goal observation and an action chunk in parallel. Iterative denoising enables global, order-free refinement, improving long-horizon consistency while grounding actions in predicted future visual outcomes without auxiliary world models. Experiments across simulation benchmarks and real-world tasks show state-of-the-art performance, achieving 98.0% average success on LIBERO and 4.78 average length on CALVIN.

*   **核心问题**：现有的视觉-语言-动作（VLA）模型主要采用分层架构（外挂策略头）或自回归生成（离散化动作）。这些方法存在以下痛点：
    *   **架构冗余**：分层设计增加了训练成本和信息损失。
    *   **时间不一致性**：自回归逐个生成动作容易导致长程任务中的误差累积。
    *   **缺乏动力学建模**：大多数模型无法在不添加额外“世界模型”模块的情况下预测环境变化。
*   **研究动机**：提出一种**原生预训练的离散扩散框架**，将理解（指令）与生成（目标图像+动作）统一，通过并行去噪提升机器人操作的精确度和长程一致性。

### 2. 方法论：核心思想与关键技术
*   **核心思想**：将语言、图像和连续动作全部映射到统一的离散 Token 空间，利用**掩码 Token 建模（Masked Token Modeling）**和**迭代去噪**并行生成未来的“目标观测”和“动作块”。
*   **关键技术细节**：
    *   **统一 Token 化**：使用 LLaDA 的文本分词器、MAGVIT-v2 图像量化器以及将连续动作离散化为 256 个 bin 的动作分词器。
    *   **混合注意力机制（Hybrid Attention）**：模态内部采用双向全注意力（Bidirectional Full Attention）以实现全局信息交换；模态之间采用因果注意力（Causal Attention）以确保信息流向。
    *   **并行生成与去噪**：模型不按顺序生成动作，而是通过 $D$ 步迭代去噪，同时细化目标图像和动作块（Action Chunk）。这种无序性避免了自回归带来的偏置。
    *   **KV 缓存优化**：为了满足实时性，对固定的指令部分进行缓存，并对生成部分进行选择性刷新。

*   **世界模型效应**：并行预测未来目标图像能显著辅助动作生成，消融实验显示去除该功能后性能大幅下降。

### 7. 优点（亮点）
*   **原生统一性**：不需要额外的策略头或独立的世界模型，在单一 Transformer 骨干中实现了感知、推理与执行。
*   **高效并行**：通过离散扩散实现了动作块的并行生成，比传统的扩散策略或自回归模型在逻辑上更简洁。
*   **混合注意力设计**：巧妙解决了多模态信息交互中的噪声干扰与特征对齐问题。

### 8. 不足与局限
*   **视觉保真度有限**：生成的未来目标图像虽然在语义上正确（如物体移动位置），但在像素级细节（如夹爪形状、复杂纹理）上存在模糊。
*   **推理延迟挑战**：尽管有 KV 缓存优化，但迭代去噪本质上仍比单次前向传播耗时，对于极高频率的控制可能存在压力。
*   **现实世界失败案例**：在处理极小开口（如细杯口）或抽屉未完全拉开等极端精度/动力学反馈场景时，仍存在失败概率。
